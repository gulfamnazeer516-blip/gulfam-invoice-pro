# Gulfam Invoice Pro

### Professional Invoice & Quotation Generator

A responsive, browser-based invoice and quotation management application built using HTML5, CSS3, and JavaScript.

## Features

- Create professional invoices and quotations
- Automatic tax, discount, and total calculations
- Live invoice preview
- Customer management
- Save, edit, and delete documents
- Print invoices or save as PDF
- Multiple currency support
- Custom business details
- JSON data backup and restore
- Browser-based local data storage

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage API

## Installation

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Start creating invoices and quotations.
